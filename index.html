menu_book Navegación

Usa los selectores del encabezado para elegir la traducción, libro y capítulo. Los botones ◀ Ant y Sig ▶ te permiten avanzar o retroceder entre capítulos, pasando automáticamente al siguiente o anterior libro cuando corresponde.

touch_app Opciones de versículo

Al tocar un versículo aparece un toolbar flotante con estas opciones:

  • Colores (🟠🟡🟢🔵🟣): Resalta el versículo con un color para marcarlo visualmente.
  • 🗑️ Quitar: Elimina el resaltado del versículo.
  • 📄 Nota: Abre el editor para crear o editar una nota asociada al versículo.
  • 📋 Copiar: Copia al portapapeles el texto del versículo con su referencia.

sticky_note_2 Notas

Las notas permiten añadir comentarios personales a cualquier versículo. Soportan sintaxis especial:

  • (Texto$https://url.com) → Crea un enlace externo.
  • (+Génesis 1:1) → Inserta una referencia bíblica que se puede tocar para ver el versículo en todas las versiones.
  • (+Génesis 1:1@nwtsty) → Referencia bíblica en una versión específica.
  • [https://url/imagen.jpg#200x=] → Inserta una imagen (usa = para tamaño automático).

Puedes añadir etiquetas (separadas por comas) para organizar tus notas. Al tocar el icono 📄 junto al número del versículo, se abre una vista previa renderizada de la nota.

bookmark Marcadores

Todos los versículos resaltados con color aparecen automáticamente en la lista de Marcadores. Desde allí puedes navegar al versículo o eliminar el resaltado.

search Búsqueda

Escribe al menos 3 letras en el buscador para encontrar coincidencias en todas las versiones y todos los libros. Los resultados se muestran resaltados y al tocar uno te lleva directamente al versículo.

list Contenido del capítulo

El botón 📑 muestra/oculta un panel con los temas y subtemas del capítulo actual (si están disponibles). Puedes expandir cada tema para ver más detalles y tocar los enlaces de versículos para navegar a ellos.

layers Modo Interlineal

En Configuración puedes cambiar entre dos modos de lectura:

  • Una traducción: Muestra solo la versión seleccionada en el selector.
  • Interlineal: Muestra cada versículo con varias traducciones apiladas, una debajo de otra, cada una con su etiqueta de versión. Ideal para estudio comparativo.

sync_alt Respaldo de datos

Usa Exportar para descargar un archivo .mbe con todas tus notas, marcadores y configuración. Usa Importar para restaurar esos datos en este u otro dispositivo.
